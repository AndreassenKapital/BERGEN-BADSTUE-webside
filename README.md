# Bergen Badstu

Landing page for Bergen Badstu — Norway's first sauna aggregator and booking platform.

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deployment

Deployed on Vercel at [bergenbadstu.no](https://bergenbadstu.no).
